# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The BrewCMS team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose any issues you find.

### How to Report

Please do **NOT** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, please send a detailed security report via email to:
**security@victorkuldeep.com** (or through private vulnerability reporting on GitHub if enabled).

In your report, please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept (PoC).
- The affected component/package (e.g. `@brew-cms/core`, `@brew-cms/auth`, `@brew-cms/api`, `@brew-cms/mcp`).
- Any potential remediations or workarounds.

### Response Process

1. **Acknowledgment**: Within 48 hours, we will acknowledge receipt of your report.
2. **Investigation**: We will verify the vulnerability and evaluate its severity.
3. **Fix and Advisory**: We will develop a patch, coordinate testing, and release a security advisory alongside the updated release.

Thank you for helping keep BrewCMS safe for everyone.
